# 📝 Proyecto Lista de Tareas

Aplicación full stack para gestionar tareas con una interfaz moderna, responsive y enfocada en una buena experiencia de usuario.

---

## 🚀 Características

- Crear tareas  
- Editar tareas  
- Eliminar tareas con confirmación  
- Marcar tareas como completadas  
- Búsqueda por título  
- Filtros por estado  
- Orden por fecha o estado  
- Resumen de tareas  
- Animaciones  
- Diseño responsive (PC y móvil)  

---

## 🛠️ Tecnologías utilizadas

### Frontend
- HTML  
- CSS  
- JavaScript (modular)  

### Backend
- Node.js  
- Express  

### Base de datos
- MongoDB Atlas  

---

## 📁 Estructura del proyecto

```bash
lista-tareas/
├── backend/
└── frontend/
```
⚙️ Instalación local

1. Clonar repositorio
git clone https://github.com/edugarra/lista-tareas.git
cd lista-tareas

2. Instalar backend
cd backend
npm install

3. Crear archivo .env
Dentro de backend/:
PORT=3000
MONGO_URI=tu_uri_de_mongodb_atlas

4. Ejecutar servidor
npm run dev

5. Ejecutar frontend

Abrir:

frontend/index.html

(Se recomienda usar Live Server)
